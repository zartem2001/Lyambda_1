# Задача: Калькулятор на функциональных интерфейсах Java

## 📋 Описание задачи

Реализовать класс `Calculator`, который использует функциональные интерфейсы Java 
(`Supplier`, `BinaryOperator`, `UnaryOperator`, `Predicate`, `Consumer`) для выполнения 
математических операций над числами.

## 🎯 Цель

Освоить практическое применение функциональных интерфейсов из пакета `java.util.function` 
и ссылок на методы (method references) в Java.

## 🛠️ Используемые технологии

- Java 17+
- Функциональные интерфейсы (`java.util.function`)
- Лямбда-выражения
- Ссылки на методы (`Calculator::new`, `System.out::println`)
